# WeCom Local Archive

将已经导出的企业微信聊天记录整理为离线图文网页和 JSONL。适合在 Mac 上保留单群历史，并把每次导出的日增量接到全量基线上。

需要 Python 3.10 或更新版本。准备自己有权使用的导出文件。归档过程中，图片和附件直接从输入目录复制到输出目录。

## 快速试用

仓库里的群聊、人物和图片均为模拟样例。运行下面命令后，在浏览器打开 `demo-output/archive.html`。

```sh
python3 wecom_archive.py examples/demo --output demo-output
```

整理实际记录时，也可以加日期范围（含首尾两天）。

```sh
python3 wecom_archive.py '/path/to/单群归档' --output archive-output \
  --start 2026-01-01 --through 2026-01-31
```

## 输入格式

每次指定一个群。可以传入聊天 Markdown 文件、包含 `聊天记录.md` 的某次导出目录，或包含全量和增量的群归档目录。

```text
单群归档/
  全量-截至-2026-01-01/
    聊天记录.md
    附件/
  2026-01-02/
    聊天记录.md
    附件/
```

文件以 `# 群名` 开头，每天用 `## YYYY-MM-DD` 分段。消息标题使用 `**HH:MM:SS · 发送者** · 消息类型`，正文缩进四个空格。图片用相对 Markdown 图片链接关联。完整格式见 [示例](examples/demo/)。

如果目录中有全量文件，工具选用截止日期最新的一份，然后纳入该日期之后的日文件。同一日期同时有独立 Markdown 和带附件的目录时，优先选择目录。旧日文件和基线日期重叠时，基线提供该日期的记录。

## 输出

- `archive.html` 按日期展示消息。可直接在浏览器打开，点击图片查看其本机文件。
- `messages.jsonl` 每行一条消息，含群名、日期、时间、发送者、类型、正文和附件信息。
- `attachments/` 保存已经匹配的本机附件。保留整个输出目录即可离线浏览。找不到的附件会在网页和 JSONL 中记录为缺失。

导出的历史范围和图片质量取决于原始导出文件。再次运行时指定一个新的输出目录。建议在准备共享之前，用模拟样例检查归档结构，真实业务记录保留在获得授权的存储位置。
